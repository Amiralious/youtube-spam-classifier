# YouTube Comment Spam Detection
This project builds a machine learning model to detect spam comments on YouTube.

# Dataset
The dataset used is the YouTube Spam Collection dataset, which contains comments collected from five popular YouTube videos.

# Project Steps
1. Load and merge multiple CSV files
2. Perform exploratory data analysis (EDA)
3. Clean and preprocess comment text
4. Convert text to numerical features
5. Train and evaluate machine learning models

# Technologies
- Python
- Pandas
- Scikit-learn
- NLP techniques

# Goal
Build a classifier that can predict whether a YouTube comment is spam or not.
